# Vishal Chaudhary – LinkedIn-Style Profile Page

This is a simple HTML-based static profile page that mimics the look and feel of a LinkedIn personal profile. It showcases the professional experience, education, certifications, and activity of **Vishal Chaudhary**, a cybersecurity expert.

## 📄 Overview

This project  layout includes:

- Header with navigation links (similar to LinkedIn)
- Hero/profile section with name, title, location, and affiliations
- Sections for:
  - About
  - Experience
  - Education
  - Certifications
  - Recommendation
  - Activity / Posts


## 🧱 Built With

- HTML5
- CSS3 (inline for simplicity)
- No frameworks or JavaScript used
