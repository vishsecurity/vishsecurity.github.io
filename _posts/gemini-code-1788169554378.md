With PCI DSS v4.0.1 being enforced, organizations must shift from point-in-time compliance to continuous security validation.

## Key Changes in PCI DSS v4.0.1

- Customized Approach for control implementation.
- Expanded multi-factor authentication (MFA) requirements across all access into the Cardholder Data Environment (CDE).
- Stricter targeted risk assessment (TRA) documentation for customized controls.

## Scope Reduction Strategies

1. **Network Segmentation:** Isolate the CDE using zero-trust network policies.
2. **Tokenization:** Replace primary account numbers (PAN) with non-sensitive tokens before storing or processing data.
3. **Outsourcing:** Leverage PCI-validated third-party service providers (TPSPs) for payment processing.
